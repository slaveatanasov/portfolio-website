## The problem

Small carriers run dispatch, drivers, loads and paperwork on spreadsheets and phone calls, while enterprise TMS products are priced and shaped for fleets many times their size. Upperway targeted that gap: a TMS a small office could adopt quickly.

## What I built

A dense, keyboard-friendly back-office UI for managing loads, drivers, trucks and the documents around them. I owned the frontend side: application architecture, shared components, state handling with RxJS, and day-to-day delivery alongside the backend team.

## Stack and decisions

Angular and TypeScript on the front end, with RxJS for data flow in a UI that updates often; Java and Spring on the API with a relational SQL model; deployed on AWS.

## Outcome

Built and shipped with a small team. The product is no longer operating; the screenshots are from the live version. More screens and usage data will be added here.
